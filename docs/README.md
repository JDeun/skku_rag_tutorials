# 읽기 자료 (docs)

노트북 실습과 함께 읽는 **개념 설명 자료**입니다. 코드를 실행하지 않고 읽기만 해도 되며, 프로그래밍·컴퓨터과학 배경이 없는 소재 연구자를 기준으로 썼습니다.

| 문서 | 다루는 내용 | 언제 읽나 |
|---|---|---|
| [01. 자료구조 기초](01_자료구조_기초.md) | 변수·자료형, 리스트, 딕셔너리, 표, JSON, DataFrame, 벡터·행렬·코사인 유사도, 그래프, 트리, 해시·인덱스, Big-O | 노트북을 시작하기 **전** |
| [02. 데이터베이스 기초](02_데이터베이스_기초.md) | DB가 필요한 이유, DBMS, 관계형 DB(SQL·정규화·ACID), NoSQL(문서형·키-값·와이드 컬럼·그래프형), 벡터 DB(ANN), 그래프 DB(LPG·Cypher), 비교표, RAG에서의 활용, 용어집 | 노트북 02 **전** (벡터·그래프 DB 절은 03·04 전에 다시) |

## 권장 읽기 순서

```
 [01 자료구조 기초] ──▶ 노트북 00 ──▶ 01 ──▶ [02 DB 기초 1~4절] ──▶ 노트북 02
                                                   │
                       [02 DB 기초 5절 벡터 DB] ──▶ 노트북 03
                       [02 DB 기초 6절 그래프 DB] ─▶ 노트북 04 ──▶ 05
                       [02 DB 기초 7~8절 비교·RAG] ─▶ 노트북 06 ──▶ 07 ──▶ 08
```

## 읽는 요령

- 각 문서는 **비유 → 그림·표 → (선택) 코드** 순서입니다. 코드 상자는 처음 읽을 때 건너뛰어도 됩니다.
- 각 문서 끝의 **핵심 요약** 3줄과 **스스로 확인해 보기** 질문으로 이해도를 점검하세요. 정답은 접혀 있습니다.
- 그림(mermaid 다이어그램)은 GitHub 웹에서 볼 때 그려집니다. 다른 편집기에서는 글자로 보일 수 있습니다.
